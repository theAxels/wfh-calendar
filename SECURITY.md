# Security Policy

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities, credentials, or private data in a public issue.

Use GitHub's **Report a vulnerability** feature in the repository's Security tab when private vulnerability reporting is available. Otherwise, contact the repository maintainers privately through a verified contact channel listed on their GitHub profile.

Include the affected file or workflow, impact, and steps to reproduce where safe. Do not include real credentials or personal data.

## Scope

The project publishes public ICS feeds and synchronizes third-party public holiday data. Do not put secrets or employee-specific information in the repository or generated feeds.
