How to subscribe

  1. Copy the feed URL using your browser's copy-link option or open the ICS link.
  2. iPhone: Settings → Apps → Calendar → Calendar Accounts → Add Account → Other → Add Subscribed Calendar. Paste the HTTPS feed URL.
  3. Google Calendar (web): Other calendars → + → From URL, then paste the HTTPS feed URL.
  4. Outlook: Add calendar → Subscribe from web, then paste the HTTPS feed URL.

Subscription refresh timing is controlled by each calendar app; updates may not appear immediately.

Generated feeds are public. Do not add private employee names or confidential details to this repository.
